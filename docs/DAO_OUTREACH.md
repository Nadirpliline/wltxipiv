**Тема:** [RFC] Automating [DAO Name] treasury operations — 67% cost savings on cross-border payments

```
## Summary

I've built Mandate, an autonomous CFO agent that automates treasury management for DAOs. I'd like to propose a pilot with [DAO Name] to demonstrate:

- **67% reduction** in cross-border payment costs (Stellar for EMEA/Africa at $0.00001/tx vs SWIFT $25-50)
- **Automated payroll**: upload contributor CSV → agent routes, screens, settles, reports
- **On-chain policy enforcement**: Soroban smart contracts with spending limits ($25k/tx, $100k/day)
- **Auditor-ready books**: double-entry accounting, trial balance, PDF export

## What I'm asking for

A **30-day pilot** with a subset of [DAO Name]'s contributor payments (e.g., 10-20 contributors in a single grants cohort). Zero risk:
- Sandbox mode (no real funds) for first 2 weeks
- Small batch ($5k-10k) with real funds for weeks 3-4
- Full transparency — all transactions on-chain, all books shared

## Demo

Working product with 59 passing tests. Here's what the agent does:
1. Reads contributor list (CSV or on-chain roster)
2. Routes each payment to cheapest chain (Stellar for EMEA/Africa, EVM L2 otherwise)
3. Screens compliance (sanctions, PEP lists)
4. Builds multisig proposals for Safe/Squads
5. Settles and records double-entry accounting
6. Produces PDF report ready for auditor

Time for 15 contributors: 0.05 seconds.

## About me

[Your background — 2-3 sentences]

I'm not asking for a grant or investment. I'm asking for permission to save [DAO Name] time and money on something that's currently done by hand. Happy to answer questions in comments or DM.

[Your name]
[Twitter] | [GitHub: link to repo]
```

**Почему работает:** Governance format (DAOs respect process), конкретное предложение (30-day pilot), zero risk (sandbox first), не просит денег.
